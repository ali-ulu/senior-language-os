# Video -> Language OS v2 Mapping

Bu sürümde video/transkriptteki yöntemler ürün davranışına çevrildi:

- Dili 20 gerçek hayat durumuna küçültme -> `realLifeMap`
- Tekil kelime yerine cümle motorları -> Sentence Engine
- Active recall + erişim hızı -> Recall Lab, <3 saniye ölçümü
- Kişisel hayat kelimeleri -> Personal Lexicon
- Dinle / yaz / metni gör / tekrar dinle -> Listening Lab + dictation
- Grameri gerçek örnekte fark etme -> Mutation Drill yapısı
- Aynı yapıyı farklı içeriklerde kullanma -> slot mutation
- İlk günden konuşma -> Speaking Mission
- Kelime bulunamayınca tarif ederek devam -> mission constraint
- Aynı konuşmayı ikinci kez yapma -> second-round rule
- 4-3-2 tekniği -> mission timer presets
- Hazırlık desteğini kademeli azaltma -> pack seviyesinde mission constraints / day progression
- En önemli 3 hataya odaklanma -> Error Loop priority Top 3
- Aynı senaryoyu değişken problemlerle tekrar etme -> mission variants
- Haftalık ses kaydı -> browser MediaRecorder desteği
- İlerlemeyi kelime sayısıyla değil performans sinyalleriyle izleme -> recall speed, active errors, completed days

Tam dil kursu içeriği bu sürümde bilinçli olarak yoktur. v2 çekirdek motordur; gerçek English/Deutsch/Türkçe içerikleri ayrı JSON paketleri olarak eklenecektir.
